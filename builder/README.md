# MathSkills Builder (prototype)

Served at https://mathskills.academy/builder/ (no login). The teacher is "Sensei" unless they type a name. They choose the curriculum first (IB, A-Level, GCSE, National Curriculum, Other; the last two ask which one), then the subject (Mathematics, Physics, Chemistry, Economics, Other), then the course (options depend on curriculum and subject, plus a free field). Languages, topics and prior skills are typed, with no pick lists: a typed language is matched to its CLDR code where possible, a typed topic that MathSkills knows gets suggested prior skills, and a typed skill that clearly names a MathSkills skill (e.g. "standard form", "laws of indices") gets its check questions. Under each skill go any number of YouTube links, website links and handouts of any type. Below is the diagnostic hexagon matrix (always seven cells, 2-3-2), and the class plan downloads as JSON. The student file at /game/ does not read the plan yet.

- `index.html` is the page that is published. It is built from `builder-src.html` by `python3 builder/assemble.py <game file> builder/builder-src.html builder/index.html`, which copies the fonts and the skill names in seven languages from the game file. The game in `game/index.html` stores those names differently, so `assemble.py` stops with an error on it; the committed `index.html` was assembled from the game version in the GitHub repository (`game-land/index.html`) and works as it is.
- Everything stays in the teacher's browser: choices in localStorage, handout files in IndexedDB. Nothing is uploaded, and no YouTube thumbnails or other outside requests are loaded.
- Language names, writing direction and decimal signs come from the browser's Unicode CLDR data (Intl). For the seven languages of the student file, its own decimal signs are used.
- Fonts: the MathSkills pixel font and Vazirmatn (SIL Open Font License, `Vazirmatn-OFL.txt`).
